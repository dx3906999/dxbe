# 设计检查清单

内置主题的验收标准。先过通用项，再看主题专项。

## 通用

**排版**

- [ ] 先有字体、栅格、行宽和层级，再谈颜色。
- [ ] 遮住 logo 和强调色，仍能通过排版辨认主题。
- [ ] 长中文、长英文、无图文章、代码块、公式、表格都能读。
- [ ] 行宽在 38–48 个汉字左右；移动端不出现横向滚动。
- [ ] 360 / 768 / 1280 / 1440 四档检查过。

**颜色**

- [ ] 一个强调色 + 两个中性色以内。
- [ ] 暗色模式单独设计，不是简单反色。
- [ ] 对比度达到 WCAG AA。
- [ ] 没有紫色/蓝色渐变 hero、玻璃拟态、漂浮光斑。

**交互**

- [ ] 键盘可以完成导航、搜索、主题切换。
- [ ] focus 可见；skip link 可用。
- [ ] `prefers-reduced-motion` 下关闭非必要动效。
- [ ] 目录高亮不遮挡正文；移动端目录可折叠。

**文案**

- [ ] UI 文案短、具体、可操作。
- [ ] 没有 emoji 标题、空泛口号、伪造数据或引用。
- [ ] 中英文分别写，不做逐字直译。
- [ ] 示例内容写具体问题，不写“欢迎来到我的博客”。

**交付**

- [ ] `npm run check:theme -- themes/<name>` 通过。
- [ ] 预览图是真实构建截图，不是概念图。
- [ ] 主题有 `i18n/zh.yml` 和 `i18n/en.yml`。
- [ ] 没有 `undefined`、`[object Object]` 或坏链接。

## folio

- [ ] 想读起来像独立杂志，不是 SaaS 落地页。
- [ ] 衬线正文、大留白、细规则线；没有卡片、阴影、渐变。
- [ ] 暗色模式是深墨底 + 米白字。
- [ ] 首页标题与站点名的重复是有意的版式选择，不是模板残留。

## orbital

- [ ] 像 70 年代技术手册 / CRT 界面，不是霓虹赛博朋克。
- [ ] 等宽元信息、编号章节、细网格；没有紫色粉青霓虹。
- [ ] 扫描线低强度、可关闭、打印时消失。
- [ ] 首页索引像目录/仪表盘，不是卡片列表。
- [ ] 浅色模式是泛黄技术纸，不是简单反色。

## scholar

- [ ] 像期刊论文，不是博客模板。
- [ ] 摘要、编号章节、左侧目录、参考文献/脚注样式成立。
- [ ] 正文衬线、适度两端对齐；移动端不产生大段空白。
- [ ] 打印样式隐藏导航和工具，正文可读。
- [ ] 没有伪造期刊名、DOI、作者单位或引用。

## apogee

- [ ] 像航天器硬件面板和检查清单，不是太空主题插画站。
- [ ] 骨白面板、方格纸、五色条纹只做结构提示；正文区域保持安静。
- [ ] 目录读起来像检查清单，编号和状态对齐。
- [ ] 入场动画只在 `prefers-reduced-motion: no-preference` 下出现。

## capstan

- [ ] 像磁带机/终端的机身，不是拟物玩具。
- [ ] 琴键按钮、荧光屏、滚轴走纸只用在框架上；正文仍是平整的纸面。
- [ ] 荧光屏色在明暗两种模式下都有足够对比。
- [ ] 动画遵守 `prefers-reduced-motion`；打印时机身装饰消失。

## 附件

- [ ] 单独一行的 `![标题](file.pdf)` 嵌入阅读器，宽度不溢出正文栏，移动端 360px 下不横向滚动。
- [ ] 不能内嵌 PDF 的浏览器（多数手机）仍能看到可点的链接。
- [ ] 打印时隐藏嵌入框，只留标题链接。
