# 0003 搜索使用 Pagefind

## 状态

已采纳。

## 背景

静态站需要全文搜索，内容以中文为主，还要按语言过滤、排除代码和公式。自己写倒排索引需要处理 CJK 分词、高亮、排序和分片。

## 决策

构建后用 Pagefind 扫描 `dist/` 建索引，主题提供搜索容器，核心提供 `search.js` 适配层。索引只包含带 `data-pagefind-body` 的文章和页面，语言通过 filter 限定。

## 后果

- 中文搜索和结果高亮开箱可用，索引按需加载。
- 多一个构建期依赖和 `dist/pagefind/` 产物。
- 搜索 UI 与主题解耦；将来替换索引实现只替换适配层。
- Pagefind 不支持中文词干，搜索按字/词匹配。
